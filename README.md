# STRUM

A guitar stood up on your phone: press frets on the neck, strum across the body. Acoustic, electric or bass.

**Play:** https://kurejas.github.io/STRUM/

- Hold strings at the frets with any number of fingers; a string plays the highest fret held on it, or rings open.
- Swipe across the strings over the body to strum (left to right is down), tap one to pluck it.
- Desktop: click a fret to latch it, Space / → strums down, ← strums up, D damps, Esc lifts every fret.

## Sounds

All real recordings from [FreePats](https://freepats.zenvoid.org/), one file per note, 256 kbps MP3:
